# AutoKeyClicker

Автокликер для Windows: нажимает клавиши или кликает мышью с заданным интервалом.
Умеет удерживать клавишу, работать ограниченное время и запускаться/останавливаться
глобальной горячей клавишей.

Интерфейс и эта инструкция — на русском. Приложение работает только в Windows.

## Возможности

- Клавиатура:
  - режим «Автоклик» — многократное нажатие клавиши или сочетания;
  - режим «Удержание» — клавиша зажата заданное время;
  - запись целевой клавиши/сочетания кнопкой «Записать».
- Мышь:
  - левая, правая или средняя кнопка (ЛКМ/ПКМ/СКМ);
  - настраиваемый интервал и время работы;
  - клики выполняются в текущей позиции курсора.
- Глобальная горячая клавиша старт/стоп (по умолчанию `F8`), работает поверх других окон.
- Защита от конфликта: горячая клавиша не должна входить в целевое сочетание.
- Статус выполнения и аккуратная остановка с отпусканием клавиш/кнопок мыши.
- Выбор языка интерфейса: русский или английский.
- Тёмная и светлая тема оформления.

## Требования

- Windows 10 или 11.
- Python 3.9 или новее (официальный установщик с python.org или версия из Microsoft Store).
- Библиотека `keyboard`.
- Для работы с окнами, запущенными от имени администратора, сам AutoKeyClicker тоже нужно
  запускать от имени администратора.

## Установка

1. Установи Python. При установке с python.org отметь галочку **Add Python to PATH**.
2. Открой папку `AutoKeyClicker` в проводнике.
3. Установи зависимость. В адресной строке проводника набери `cmd` и нажми Enter, затем выполни:

   ```bat
   python -m pip install -r requirements.txt
   ```

   Можно установить и вручную:

   ```bat
   python -m pip install keyboard
   ```

4. Запусти `run.bat` (без консольного окна) или `python AutoKeyClicker.py`
   (с консолью — удобнее, если нужно увидеть ошибки).

Дополнительно устанавливать приложение не нужно: это обычная папка, её можно хранить где угодно.

## Быстрый старт

1. Выбери устройство: **Клавиатура** или **Мышь**.
2. Настрой параметры:
   - для клавиатуры — режим, клавишу/сочетание, интервал, время работы или удержание;
   - для мыши — кнопку, интервал и время работы.
3. Нажми **Начать** или горячую клавишу (по умолчанию `F8`).
4. Повторное нажатие горячей клавиши или кнопка **Остановить** останавливает кликер.
5. Статус внизу окна показывает, что происходит: «Остановлен», «Работает — …» или текст ошибки.

Пока кликер работает или ждёт запись клавиши, настройки и переключатель устройства заблокированы.
Сначала останови кликер.

## Как пользоваться

### Клавиатура

**Режим «Автоклик»**

- «Интервал автоклика, мс» — пауза между нажатиями. `100` = 10 нажатий в секунду.
- «Время работы, сек» — сколько времени кликать. `0` — бесконечно, до остановки.
- «Что нажимать» — клавиша или сочетание. Примеры:
  `a`, `1`, `tab`, `space`, `shift`, `f5`, `alt+q`, `ctrl+shift+s`.
- Названия клавиш указывай на английской раскладке (`a`, а не `ф`; `enter`, а не «ввод»).
- Кнопка **Записать** позволяет нажать клавишу/сочетание и подставить его автоматически.

**Режим «Удержание»**

- «Длительность удержания, сек» — сколько держать клавишу/сочетание. `0` — держать до остановки.
- Все клавиши сочетания зажимаются одновременно и отпускаются в обратном порядке.

**Горячая клавиша**

- Поле «Горячая клавиша старт/стоп» можно заполнить вручную (`f9`, `ctrl+alt+k`) и нажать Enter
  или кнопку **Записать**.
- Горячая клавиша не может состоять только из модификаторов (`ctrl`, `alt`, `shift`, `windows`).
- Горячая клавиша не должна целиком входить в целевое сочетание. Например, цель `ctrl+s`
  и горячая `s` конфликтуют: кликер нажмёт `s` и остановит сам себя. При конфликте приложение
  покажет ошибку и не запустится.
- Если горячая клавиша не срабатывает, проверь, не занята ли она другой программой.

### Мышь

- **Кнопка мыши**: ЛКМ (левая), ПКМ (правая), СКМ (средняя).
- **Интервал между кликами, мс** — пауза между кликами.
- **Время работы, сек** — `0` означает «до остановки».
- Кликер не двигает курсор: клики происходят там, где курсор находится сейчас.
  Перед запуском поставь курсор на нужное место.
- При остановке приложение всегда отпускает кнопку мыши, даже если кликер остановили посередине.

### Общие замечания

- Язык интерфейса (русский/английский) и тема (светлая/тёмная) выбираются выпадающими
  списками в правом верхнем углу окна и применяются сразу, без перезапуска.
- Интервал задаётся в миллисекундах и не может быть отрицательным. `0` — максимально быстро;
  это сильно нагружает процессор, используй осторожно.
- Точность интервала зависит от нагрузки системы. Пока приложение открыто, оно поднимает
  разрешение системного таймера, но идеальная точность не гарантируется.
- На экране блокировки, в UAC-запросах и в некоторых защищённых приложениях ввод не работает.
- В играх с античит-защитой синтетические нажатия могут блокироваться. Используй с учётом правил
  приложения/игры.

## Ярлык на рабочем столе

### Создание

1. Открой папку `AutoKeyClicker`.
2. Дважды щёлкни `create_shortcut.bat`.
3. Дождись сообщения «Готово» и нажми любую клавишу, чтобы закрыть окно.
4. На рабочем столе появится ярлык **AutoKeyClicker**. Если рабочий стол перенаправлен в OneDrive,
   ярлык появится в OneDrive.

Что делает `create_shortcut.bat`:

- копирует маленький лаунчер `launcher.py` и иконку в `%USERPROFILE%\.autokeyclicker`;
- запоминает текущее расположение папки с программой;
- создаёт ярлык на рабочем столе. Ярлык запускает `pythonw.exe` с лаунчером, а не папку напрямую.

### Перемещение папки

Папку с программой можно перемещать куда угодно, пересоздавать ярлык не нужно.

- Ярлык не хранит путь к папке приложения. Он запускает лаунчер из
  `%USERPROFILE%\.autokeyclicker`, а лаунчер сам находит `AutoKeyClicker.py`.
- Сначала лаунчер проверяет сохранённый путь. Если папку переместили, путь становится
  недействительным, и лаунчер ищет программу:
  - на рабочем столе, в «Документах», «Загрузках»;
  - в профиле пользователя и в OneDrive;
  - на локальных дисках (не глубже 4 уровней, системные папки пропускаются).
- Найденный путь сохраняется, поэтому следующие запуски происходят сразу.
- Если папка оказалась в совсем нестандартном месте и автопоиск не сработал, лаунчер один раз
  попросит выбрать папку с `AutoKeyClicker.py` и запомнит её.
- Рекомендуется закрыть AutoKeyClicker перед перемещением папки, хотя обычно это не обязательно.

### Важно про служебную папку

Не удаляй `%USERPROFILE%\.autokeyclicker` — там лежат лаунчер, иконка и сохранённый путь.
Это папка в корне профиля пользователя (рядом с «Документами» и OneDrive). Чтобы открыть её,
вставь `%USERPROFILE%\.autokeyclicker` в адресную строку проводника.

Если случайно удалил:

- запусти `create_shortcut.bat` из папки программы — ярлык и служебные файлы создадутся заново.

Если удалил сам ярлык:

- снова запусти `create_shortcut.bat`.

Если ярлык не запускается, посмотри лог:
`%USERPROFILE%\.autokeyclicker\launcher.log`.

### Ручное создание ярлыка

Обычный ярлык, созданный через «Отправить → Рабочий стол», указывает на конкретный файл и
сломается при перемещении папки. Поэтому используй `create_shortcut.bat`.

Если нужно создать ярлык вручную, сделай его на `%USERPROFILE%\.autokeyclicker\launcher.py`
(запуск через `pythonw.exe`). Но проще один раз запустить `create_shortcut.bat`.

## Файлы

- `AutoKeyClicker.py` — само приложение.
- `run.bat` — запуск приложения из текущей папки (путь не прописан, папку можно перемещать).
- `launcher.py` — лаунчер, который ищет папку с приложением; копируется в `%USERPROFILE%\.autokeyclicker`.
- `create_shortcut.py` — создание ярлыка и служебных файлов.
- `create_shortcut.bat` — удобный запуск `create_shortcut.py` двойным щелчком.
- `requirements.txt` — зависимости Python.
- `AutoKeyClicker.ico` — иконка приложения и ярлыка.
- `README.md` — эта инструкция.

## Обновление и удаление

**Обновление**

1. Закрой AutoKeyClicker.
2. Замени файлы в папке на новую версию.
3. Если в новой версии изменились лаунчер или иконка, запусти `create_shortcut.bat` ещё раз.
4. Если изменились зависимости: `python -m pip install -r requirements.txt`.

**Удаление**

1. Удали ярлык с рабочего стола.
2. Удали папку с программой.
3. При желании удали `%USERPROFILE%\.autokeyclicker` (лаунчер, иконка, кэш пути, лог).
4. Библиотеку `keyboard` можно оставить — она может использоваться другими программами.

## Решение проблем

**«Не найдена библиотека keyboard»**

```bat
python -m pip install keyboard
```

**Приложение не запускается из `run.bat`**

Запусти в консоли:

```bat
python AutoKeyClicker.py
```

Так будет виден текст ошибки. Проверь, что Python установлен и доступен команде `python`.

**Ярлык не запускает приложение**

- Запусти `create_shortcut.bat` заново.
- Проверь лог `%USERPROFILE%\.autokeyclicker\launcher.log`.
- Убедись, что папка `%USERPROFILE%\.autokeyclicker` не удалена.
- Если менял версию Python, пересоздай ярлык: старый путь к `pythonw.exe` мог исчезнуть.

**Горячая клавиша не срабатывает**

- Выбери другую комбинацию: её может перехватывать другая программа.
- Для окон, запущенных от администратора, запусти AutoKeyClicker от администратора.
- В некоторых играх и защищённых приложениях глобальные хуки не работают.

**Клавиши нажимаются не туда**

AutoKeyClicker отправляет ввод в активное окно. Перед запуском переключись в нужное окно.
Названия клавиш пиши на английской раскладке.

**Мышь кликает не туда**

Кликер не перемещает курсор. Поставь курсор в нужную точку до запуска и не двигай его.
Для проверки начни с маленького времени работы.

**Антивирус ругается**

Приложение использует глобальный хук клавиатуры (библиотека `keyboard`) — некоторые антивирусы
реагируют на такое поведение. Исходный код открыт и лежит в папке; при необходимости добавь папку
в исключения.

## Безопасность

Кликер генерирует настоящие нажатия клавиш и клики мыши. Перед запуском убедись, что активное окно
и позиция курсора безопасны, а время работы ограничено. Горячая клавиша останавливает кликер
в любой момент.
